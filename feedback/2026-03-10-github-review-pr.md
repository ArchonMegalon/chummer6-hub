# GitHub Codex Review

PR: https://github.com/ArchonMegalon/chummer.run-services/pull/1

Findings:
- [high] Chummer.Run.AI/Services/Session/OfflineSyncService.cs : line 69 Offline reconcile merges snapshot events with `LocalPendingEvents` without validating that every event matches `Snapshot.SessionId`/`Snapshot.SceneId`. Because ledger merge keys off the first event, cross-session/scene events can be silently ignored or merged under the wrong boundary. Validate and reject mismatched events before calling `MergeEventsAsync`.
- [high] Chummer.Run.Contracts/SessionRelayContracts.cs : line 3 Public relay DTOs moved from `Chummer.Run.Contracts.AI` to `Chummer.Run.Contracts.Relay` and legacy `SessionOverlayEventDto` is removed from the contracts assembly with no public shim/type-forwarding. This is a source/binary compatibility break for existing `Chummer.Run.Contracts` consumers; add explicit compatibility forwarding/shims or gate as a versioned breaking-change migration.
- [medium] .codex-design/product/PROGRAM_MILESTONES.yaml : line 281 The mirrored design bundle is not fully synced: this file diverges from canonical `/docker/chummercomplete/chummer-design/products/chummer/PROGRAM_MILESTONES.yaml` by appending `repo_execution_tracks`. For the 'sync approved bundle' slice, keep repo-local execution overlays outside mirrored product canon or re-sync this file exactly.
- [medium] Chummer.Run.Contracts/HubRegistryContracts.cs : line 188 Run public contracts now expose `HubArtifactStore*Snapshot` and `HubArtifactStoreBackupPackage` (including dead-letter/backup internals), which leaks registry store internals across the boundary and increases contract drift risk. Move backup/store-internal DTOs to internal/admin-only surfaces or a dedicated internal contract package.
- [medium] Chummer.Run.Contracts/Chummer.Run.Contracts.csproj : line 4 Contracts project depends on sibling binaries via `Reference` + `HintPath` into `bin/$(Configuration)` outputs instead of deterministic project/package references. This introduces build-order and stale-binary compatibility hazards (same pattern also present in `Chummer.Run.AI/Chummer.Run.AI.csproj`). Replace with `ProjectReference`/`PackageReference`.
