# Whole Project Missed Scope Acceptance

This file turns the broad "whole project" audit request into an executable acceptance contract. It is a source design document, not a generated proof artifact.

## Additional Goal

Chummer is not gold until every user-facing release, support, install, desktop, rules, Origin Dossier, Alice, provider, and public website claim has:

- one source of truth;
- a first-party route;
- a current proof;
- a human-readable surface;
- and an exit gate that fails stale, noisy, unreadable, or contradictory output.

## Scope Lanes

- Public release and downloads truth
- Desktop visual and behavior parity
- Installer, updater, and account-linking trust
- Origin Dossier and Alice
- Rules authority and explainability
- Instant Help and support repair
- Provider and LTD governance
- Website humanization and public copy
- Evidence freshness and final gold proof chain

## Must Fail If

- generated receipts regress release truth;
- public pages read like proof artifacts;
- normal Chummer help routes to calendar booking;
- the user has to guess the next step;
- dark or OS theme settings can hide controls;
- Origin Dossier starts with provider or media choices before story;
- Alice invents rules or release truth;
- a provider owns final truth;
- or the final gold artifact is stale or non-reproducible.

## Acceptance

- Audited current sources and live surfaces agree.
- Tests cover user journeys, not only static text.
- Design docs say the same thing as repo behavior.
- Stale or regressive generated proof artifacts are excluded or regenerated before promotion.
- One daily morning publish cadence is respected unless a human explicitly approves an emergency publish.
