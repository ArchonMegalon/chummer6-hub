# User Wishes and Missed Potential

This canon closes the gap between the user-wish expansion audit and the current shipped estate.

## What users are asking for

- first-party package browsing, follow, and governed adoption instead of scattered file handling
- mobile and PWA entry routes that clearly state what works today
- support, feedback, and Karma Forge loops that stay visible after submission
- creator and GM outputs with provenance instead of copy-paste folklore
- honest public copy that never asks users to decode internal tooling or repo structure

## Missed potential now promoted to canon

- package management is a real product plane, not a future aside
- mobile continuity is part of the public front door, not a hidden repo claim
- janitor and public-polish work are release gates, not cleanup chores
- public trust depends on first-party receipts, retention posture, and source-safe submission rules

## Governing rule

No new public promise may bypass central design canon, Hub mirror publication, route proof, and a claim-to-proof diff.
