# RUNNER PASSPORT

## What is ready now

Runner Passport is now a shipped first-party continuity lane.

Public-safe trust posture, bounded cross-table participation proof, and signed-in return rails all live on named Chummer routes instead of vague organizer workflow.

## Live routes

* `/passport`
* `/passport/receipts/identity-network.json`
* `/account/passport`
* `/account/passport/open`

## What it does

* exposes aggregate runner return posture without publishing private identity recovery
* keeps cross-table participation proof bounded and receipt-backed
* points signed-in users back to the live Table Pulse inbox, leader command, and aftermath return lane

## Boundary

Runner Passport is not:

* a hidden surveillance score
* public moderation truth
* a permanent provider-owned reputation engine

The public surface stays aggregate and trust-safe. Private identity links, moderation state, and account recovery stay on signed-in Chummer rails.
