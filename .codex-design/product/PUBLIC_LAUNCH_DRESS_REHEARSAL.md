# Public Launch Dress Rehearsal

The dress rehearsal is the last release control loop before any public flagship claim.

## Must prove together

- clean build and publish posture
- release shelf, checksums, and channel truth
- account, download, install, and support continuity
- feedback and Karma Forge receipt flows
- package browser and mobile/PWA public projection
- rollback posture and release notes coherence

## Fail-closed rule

If any required leg skips, the skip must be written into `SKIP_LEDGER.generated.yaml` with an owner, replacement proof, and release impact.
