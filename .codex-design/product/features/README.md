# Product features

These docs are source source notes for Chummer base-client features that should read as normal product areas, not Horizons.

Use this folder for mature or first-party product surfaces such as NEXUS-PAN, Run Control, Edition Studio, Community Hub, Ghostwire, Local Co-Processor, and Quicksilver.

Use `products/chummer/horizons/` only for true expansion bets and deeper design lanes that should stay framed as Horizons.
