# QUICKSILVER

A veteran user jumps from ALICE to rules answers to RUNSITE prep to publication desks without losing context or trusting a fake launcher.

## Current stage

- Today: Shipped first-party command deck.
- Next: Flagship depth hardening.

## What it does now

QUICKSILVER is the expert-speed lane for the same trusted Chummer surfaces.

It currently ships:

* a public command route at `/quicksilver`
* a named receipt at `/quicksilver/receipts/command-network.json`
* packet rails for the command deck and jump targets
* a signed-in command deck at `/account/quicksilver`
* typed command APIs for jump targets and lead routes

The speed lane does not replace ALICE, RUNSITE, JACKPOINT, Creator OS, or the rules lane.
It makes those first-party rails faster to reach and easier to keep in one mental frame.

## Boundary

QUICKSILVER does not claim:

* hidden automation authority
* legality shortcuts
* cache-based truth
* a second rules engine

It is a shipped command deck, but it stays bounded to explicit first-party routes and typed receipts.
